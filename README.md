# Hebrew Date Converter

A browser-based app that converts Gregorian dates to Hebrew dates using the [Hebcal API](https://www.hebcal.com/home/219/hebrew-date-converter-rest-api). Choose whether the date is before or after sunset, and the result appears in Hebrew.

## Run locally

Download or clone this repository, then open `index.html` in your browser. An internet connection is required for date conversion.

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Date input, sunset selection, and result display |
| `script.js` | Form handling, Hebcal API requests, and error handling |
| `style.css` | Responsive layout and styling |
